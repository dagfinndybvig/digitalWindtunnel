# wing3d — 3-D Wing Generator for Eppler Airfoils

Generates a fully lofted, 3-D wing as an ASCII STL file from one or two
**`profile.out`** files produced by the Eppler program.

This folder is completely self-contained.  It has no dependencies on the rest
of the `digitalWindtunnel` repository and requires only the Python standard
library (no `pip install` needed).

---

## Prerequisites

- Python 3.10 or later
- A `profile.out` file generated by running the Eppler program
  (`bin/profile` or `bin/profile.exe` in the parent repository)

---

## Quick start

```bash
# 1. Run the Eppler program to produce profile.out
#    (from the repository root)
.\bin\profile.exe
# > enter: data\input\e1098.dat

# 2. Generate the wing STL with all defaults
python wing3d/wing_to_stl.py profile.out

# Output: wing.stl  (300 mm span, 100 mm root chord, tapered, 15° sweep)
```

---

## Usage

```
python wing_to_stl.py <root_profile> [tip_profile] [options]
```

### Positional arguments

| Argument | Description |
|---|---|
| `root_profile` | Path to `profile.out` for the **root** cross-section (required) |
| `tip_profile` | Path to `profile.out` for the **tip** cross-section (optional) |

When `tip_profile` is omitted the same airfoil shape is used from root to tip;
only chord, twist, sweep and dihedral vary along the span.

When two different profiles are supplied the shape is **smoothly interpolated**
(blended) between root and tip at each spanwise station.

### Options

| Flag | Default | Description |
|---|---|---|
| `-o`, `--output` | `wing.stl` | Output STL file path |
| `--span-mm` | `300` | Half-span length in mm |
| `--root-chord-mm` | `100` | Root chord length in mm |
| `--taper` | `0.6` | Taper ratio = tip chord / root chord (0 < taper ≤ 1) |
| `--sweep-deg` | `15` | Leading-edge sweep angle in degrees |
| `--dihedral-deg` | `3` | Dihedral angle in degrees |
| `--washout-deg` | `-2` | Geometric twist at the tip in degrees (negative = washout) |
| `--tip` | `flat` | Tip cap style: `flat` or `round` |
| `--sections` | `20` | Number of spanwise loft sections (higher = smoother) |

## Examples

### Rectangular wing, no sweep, flat tip
```bash
python wing_to_stl.py profile.out \
    --span-mm 400 --root-chord-mm 80 --taper 1.0 \
    --sweep-deg 0 --dihedral-deg 0 --washout-deg 0 \
    --tip flat -o rect_wing.stl
```

### Tapered, swept wing with rounded tip
```bash
python wing_to_stl.py profile.out \
    --span-mm 300 --root-chord-mm 100 --taper 0.45 \
    --sweep-deg 20 --dihedral-deg 5 --washout-deg -3 \
    --tip round -o swept_wing.stl
```

**Output:**
```
Root profile : profile.out
Tip  profile : profile.out

Building wing 'wing_NACA2412':
  Span        : 300.0 mm
  Root chord  : 100.0 mm
  Tip chord   : 45.0 mm  (taper 0.45)
  Sweep       : 20.0°
  Dihedral    : 5.0°
  Washout     : -3.0°
  Tip style   : round
  Sections    : 20

Wrote swept_wing.stl  (2682 triangles)
```

The resulting file `swept_wing.stl` is included in this folder as a ready-to-use reference model.

### Different root and tip airfoils(shape interpolation)
```bash
# Run the Eppler program twice to get two profile.out files
.\bin\profile.exe   # enter data\input\e1098.dat  → save as root.out
.\bin\profile.exe   # enter data\input\e864.dat   → save as tip.out

python wing_to_stl.py root.out tip.out \
    --span-mm 350 --root-chord-mm 120 --taper 0.5 \
    --sweep-deg 15 --tip round -o blended_wing.stl
```

### High-resolution model for rendering
```bash
python wing_to_stl.py profile.out --sections 60 -o wing_hires.stl
```

## Geometry reference

```
            Z (span) →
            |
 root ──────┼──────────────── tip
            |
            ↑ Y (lift)

 X = chordwise (leading edge at small X)
```

- **Sweep** offsets the leading edge in the X direction as span increases.
- **Dihedral** lifts the tip in the Y direction.
- **Washout** rotates each section nose-down (negative degrees) about the
  quarter-chord point, linearly from 0° at root to the specified value at tip.
- **Taper** reduces the chord linearly from root to tip.

---

## Output

An **ASCII STL** file suitable for:
- 3-D printing (import into PrusaSlicer, Cura, etc.)
- CAD inspection (FreeCAD, Fusion 360, Blender, MeshLab, …)
- Further mesh processing

Triangle count is approximately:

```
triangles ≈ 2 × sections × profile_points  +  2 × (profile_points − 2)
```

With defaults (`sections=20`, ~60 profile points): roughly **2 500 triangles**.

---

## How it works

1. **Parse** — reads the `N  X  Y` coordinate table from each `profile.out`.
2. **Resample** — both profiles are arc-length resampled to the same point
   count so they can be blended.
3. **Loft** — at each of `sections + 1` spanwise stations the profile is:
   - interpolated between root and tip shapes,
   - twisted by the linearly-varying washout angle,
   - scaled by the local chord,
   - translated by the sweep and dihedral offsets.
4. **Cap** — the root face is closed with ear-clip triangulation; the tip is
   either flat (ear-clip) or rounded (two-band dome).
5. **Write** — outputs an ASCII STL with outward-facing normals.

No external libraries are used — everything is pure Python.
